# OpenFDE FrontEnd

React prototype for the agent-design experience. The current slice includes:

- Agents and Connectors navigation
- transient `/agents/new` chat (no persisted agent until the first message)
- resumable design conversations and design briefs
- a simple React Flow canvas with a plain-language node library
- browser-local prototype persistence until backend contracts land

## Run

```bash
npm install
npm run dev
```

## Verify

```bash
npm run test
npm run build
```
